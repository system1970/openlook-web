# Orkestrate Web QA Test Reports

This directory contains **QA test reports generated by the Orkestrate Web MCP server**.

## Purpose

When the MCP server completes a test session, it generates:
- **Test reports** with observations, actions, and evaluations
- **Screenshots** captured during testing
- **AI evaluation results** from Gemini vision analysis
- **Session metadata** and timing information

These reports document:
- Browser automation test results
- Visual QA findings
- AI-powered evaluation outcomes
- Test execution history

## What Goes Here

✅ **Orkestrate QA Reports**:
- Test session reports (JSON or Markdown)
- Screenshots from browser automation
- Evaluation summaries
- Test execution logs

❌ **Not Here**:
- Bob IDE task exports (those go in `bob_sessions/`)
- Source code or configuration
- API keys or secrets

## Report Structure

### Test Report Format

```json
{
  "sessionId": "session_1234567890_abc123",
  "url": "https://example.com",
  "startedAt": "2026-05-15T10:00:00Z",
  "completedAt": "2026-05-15T10:05:00Z",
  "duration": 300000,
  "status": "passed",
  "summary": "All checks passed",
  "observations": [...],
  "actions": [...],
  "evaluations": [...],
  "screenshots": [...]
}
```

### File Naming Convention

```
report_YYYYMMDD_HHMMSS_sessionId.json
screenshot_YYYYMMDD_HHMMSS_NNN.png
```

Example:
```
report_20260515_100000_session_abc123.json
screenshot_20260515_100000_001.png
screenshot_20260515_100000_002.png
```

## Report Types

### 1. Session Report
Complete test session with all observations, actions, and evaluations.

### 2. Evaluation Report
AI-powered analysis of page state vs. expectations.

### 3. Screenshot Archive
Visual evidence of test execution.

## Separation of Concerns

**Orkestrate Reports** (this directory):
- Automated QA test outputs
- Browser automation results
- AI evaluation findings

**Bob Sessions** (`bob_sessions/` directory):
- Bob IDE task documentation
- Hackathon evidence
- Human-readable workflow logs

These serve different purposes and should remain separate.
